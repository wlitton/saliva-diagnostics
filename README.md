# Saliva Diagnostics

Basic Flutter boilerplate for a saliva diagnostics-themed food diary app.

## Getting started

1. Install the Flutter SDK and run `flutter doctor` to verify your setup.
2. Get dependencies:

   ```sh
   flutter pub get
   ```

3. Run the app:

   ```sh
   flutter run
   ```

4. Run tests:

   ```sh
   flutter test
   ```

## Camera and photos

The app uses `image_picker` to take photos or upload from the gallery. If you
add Android/iOS targets, be sure to add the required camera and photo library
permissions for each platform.
