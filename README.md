# Saliva Diagnostics

Basic Flutter boilerplate for a saliva diagnostics-themed app.

## Getting started

1. Install the Flutter SDK and run `flutter doctor` to verify your setup.
2. Get dependencies:

   ```sh
   flutter pub get
   ```

3. Run the app:

   ```sh
   flutter run
   ```

4. Run tests:

   ```sh
   flutter test
   ```
